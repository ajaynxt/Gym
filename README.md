```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## GitHub Pages deployment
1. Create a new public repository, for example `ironpulse-gym-demo`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Set Source to **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. In the custom domain field, enter `gym.ajaynxt.com`.
7. At the domain provider, add a CNAME record: Host `gym`, Value `<your-github-username>.github.io`.
8. Enable **Enforce HTTPS** after DNS verification.

The included `CNAME` file already contains `gym.ajaynxt.com`.

## Client Preview and Lock System

The floating **Client Preview** panel lets a customer compare four color systems and three copywriting systems directly on the live website.

- **Color lock:** saves the selected theme in the browser.
- **Text lock:** saves the selected message style in the browser.
- **Save & Lock Both:** freezes both selections for that browser.
- **Download Client Choice:** downloads a ready-to-upload `site-config.js`. Replace the repository's existing `site-config.js` with this file to permanently lock the client's final choice across all devices.

All visible headings and descriptions remain real HTML text. Every gym visual uses a separate Pexels stock photograph; no website screenshot is used as a page section.
