# Client Preview: Color and Text Lock

1. Open the website and tap **Client Preview**.
2. Compare any of the four color systems.
3. Compare **Sales Focused**, **Premium Coaching**, and **Community Energy** text.
4. Tap **Save & Lock Both** when the client chooses.
5. Tap **Download Client Choice**. A new `site-config.js` file downloads.
6. Upload that downloaded file to the repository root and replace the old `site-config.js`.

This makes the selected theme and text permanent on all devices.

The website uses separate Pexels image URLs. It does not use any full-page mockup or screenshot crop as website content.
