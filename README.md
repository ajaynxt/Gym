
Then open `http://localhost:8080`.

## GitHub Pages deployment
1. Create a new public repository, for example `ironpulse-gym-demo`.
2. Upload all files from this folder to the repository root.
3. Open **Settings → Pages**.
4. Set Source to **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. In the custom domain field, enter `gym.ajaynxt.com`.
7. At the domain provider, add a CNAME record: Host `gym`, Value `<your-github-username>.github.io`.
8. Enable **Enforce HTTPS** after DNS verification.

The included `CNAME` file already contains `gym.ajaynxt.com`.
